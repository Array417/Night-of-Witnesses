# Card art

Generated with the built-in ImageGen tool using visual references to the original Night of Witnesses card art: compact chibi characters, bold ink contours, flat colors and mustard backgrounds; atmospheric painted manor locations.

Reference photos are used only during generation and are not shipped in the app:
- https://www.punchboardgame.com/blog/posts/目擊者之夜-night-of-witnesses-繁體中文版-開箱及規則介紹-高雄龐奇桌遊
- https://usnoopy.blogspot.com/2020/12/witness-night.html

The earlier graphic-novel images were superseded at the user's request and are not used by the app. All delivered illustrations are newly generated, contain no printed rules or labels, and are encoded as WebP for web delivery. Labels are rendered by the application.

Files: eight roles, six player locations, Guest Room, Boiler Room, and one generic back. Opponent card backs always use the same image. Full generation prompts are recorded in docs/card-art-prompts.json.
